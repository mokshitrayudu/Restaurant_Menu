# Spice Garden | Restaurant Menu Website

A responsive restaurant menu website built using **HTML** and **CSS**.  
It displays **25 dishes** organized into categories such as Starters, Main Course, Breads & Rice, Desserts, and Beverages.

## Features

- Fully responsive design for mobile, tablet, and desktop
- Clean card-based menu layout using CSS Grid
- 25 dishes across 5 categories
- Dish name, price, and short description for every item
- Smooth hover effects on menu cards
- Simple and beginner-friendly HTML/CSS code
- No JavaScript required

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Web Design

## Categories

- Starters — 5 dishes
- Main Course — 8 dishes
- Breads & Rice — 4 dishes
- Desserts — 4 dishes
- Beverages — 4 dishes

## Purpose

This project is suitable for learning HTML and CSS layout concepts, especially responsive grids, typography, colors, and hover effects.
